# Individual character sprite sheets

Flat, colorful Nintendo-like console game style: clean rounded 2D forms, simple fills, and minimal cel shading.

## Uniform format
- **14 sheets total**
- **1024 × 1024 px each**
- **6 columns × 6 rows**
- **36 equal 170 × 170 frame cells** inside a 2 px sheet margin
