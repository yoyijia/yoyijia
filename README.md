# yoyijia

Personal projects for [Yijia](https://github.com/yoyijia).

## Sprig — intern daily log

A cute daily log for internship work: **things to do**, **things done**, mood, and a soft note.

- Source: [`intern-log/`](./intern-log/)
- Free site (GitHub Pages): **https://yoyijia.github.io/yoyijia/log/**
- Data stays in your browser (`localStorage`) — nothing is uploaded.

### Local preview

```bash
cd intern-log
python3 -m http.server 5173
```

Then open http://localhost:5173
